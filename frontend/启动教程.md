# frontend-vue3-refactor 启动教程

## 需要的软件

- `Node.js` 22+
- `npm`
- `Chrome` 或 `Edge`

Node.js 安装参考教程：

[2026 最新版 Node.js 安装及环境配置教程（Win11）](https://blog.csdn.net/little_carter/article/details/157698232)

安装完成后，请先在终端执行以下命令确认安装成功：

```powershell
node -v
npm -v
```

## 项目脚本

项目脚本定义在 `package.json` 中，主要命令如下：

- `npm run dev`
  启动开发环境
- `npm run build`
  生成生产构建文件
- `npm run preview`
  预览构建结果

## 启动命令

打开终端，进入 `frontend-vue3-refactor` 项目目录后执行：

```powershell
npm install
npm run dev
```

## 补充说明

- 仅完成 Node.js 安装还不能直接启动项目
- 需要在项目目录执行 `npm install` 安装依赖后，再执行 `npm run dev`
- 项目可在当前目录独立启动
- 构建产物输出在 `dist/` 目录
