# 七个程序启动命令（Windows）
适用目录：`E:\AI内容自动化\backend\agent-stack`

建议打开 7 个终端窗口，按下面顺序启动。

## 1) 签名服务 `sign-service`（默认 8989）
```bat
cd /d E:\AI内容自动化\backend\agent-stack\sign-service
python app.py
```

## 2) 下载解析服务 `download-service\DownloadServer`（默认 8205）
```bat
cd /d E:\AI内容自动化\backend\agent-stack\download-service\DownloadServer
python app.py
```

## 3) Cookie 桥接服务 `cookie-bridge`（默认 8274）
一键启动：

```bat
cd /d E:\AI内容自动化\backend\agent-stack\cookie-bridge
start.bat
```

手动启动：
```bat
cd /d E:\AI内容自动化\backend\agent-stack\cookie-bridge\server
uv sync
uv run app.py
```

## 4) AI Agent 后端 `ai-agent-service\backend`（示例端口 8002）
```bat
cd /d E:\AI内容自动化\backend\agent-stack\ai-agent-service\backend
uv run --python 3.12 --no-editable --no-sync python -m uvicorn api.main:app --host 0.0.0.0 --port 8002
```

## 5) 爬虫常驻 HTTP API `crawler-engine\api_server.py`（默认端口 8005）
```bat
cd /d E:\AI内容自动化\backend\agent-stack\crawler-engine
uv run python api_server.py
```

## 6) AI Agent 前端 `ai-agent-service\frontend`（Vite）
```bat
cd /d E:\AI内容自动化\backend\agent-stack\ai-agent-service\frontend
npm install
npm run dev
```
