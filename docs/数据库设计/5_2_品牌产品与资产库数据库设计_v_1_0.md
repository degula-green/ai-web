# 5.2 品牌产品与资产库数据库设计 v1.0

## 1. 文档说明

本文档用于设计“品牌产品与资产库”模块的数据库结构。该模块旨在沉淀品牌与产品的核心资产，包括产品档案、营销卖点以及多媒体素材，为后续的 AI 内容创作提供高标准的基础输入。

### 核心目标：
- **档案标准化**：统一存储产品定位、目标人群、调性等基础信息。
- **卖点管理**：系统化整理营销卖点，支持针对不同平台和场景的筛选。
- **资产归集**：集中管理品牌视觉素材，支持按标签、场景和产品关联查询。
- **合规管控**：维护品牌禁用词库，确保 AI 生成内容符合品牌调性与合规要求。

统一命名建议：
- MySQL 表名前缀：`brand_`
- 主键统一使用 `BIGINT UNSIGNED`
- 时间统一使用 `DATETIME`
- 复杂对象（如禁用词数组、适用平台）统一使用 `JSON` 类型。

## 2. 数据库设计总览

| 表名 | 用途 | 说明 |
| --- | --- | --- |
| `brand_products` | 品牌产品档案表 | 存储品牌基本信息、产品定位、人群及禁用语 |
| `brand_selling_points` | 营销卖点库 | 存储产品的核心卖点、权重及平台适用性 |
| `brand_visual_assets` | 视觉素材库 | 存储品牌图片、视频、Logo 等多媒体资产 |

## 3. 表设计详情

### 3.1 `brand_products` 品牌产品档案表

用途：存储品牌与产品的元数据，是内容生成的上下文来源。

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| `id` | BIGINT UNSIGNED | 主键ID |
| `user_id` | BIGINT UNSIGNED | 归属系统用户ID，对应 `iam_users.id` |
| `brand_name` | VARCHAR(64) | 品牌名称（如：智创网络） |
| `product_name` | VARCHAR(128) | 产品/生产线名称（如：智创内容自动化矩阵 v3） |
| `positioning` | TEXT | 产品定位 |
| `target_audience` | TEXT | 目标人群 (Target Audience) |
| `scenarios` | TEXT | 适用场景 (Scenarios) |
| `tone_voice` | VARCHAR(255) | 整体调性 (Tone & Voice) |
| `forbidden_phrases` | JSON | 禁用表达/风险词，数组格式：["便宜", "免费试用", ...] |
| `cover_url` | VARCHAR(512) | 档案封面图片 URL |
| `is_deleted` | TINYINT(1) | 逻辑删除标记：0否，1是 |
| `created_at` | DATETIME | 创建时间 |
| `updated_at` | DATETIME | 更新时间 |

**索引建议：**
- `idx_user_brand`：`user_id + brand_name`
- `idx_product_name`：`product_name`

---

### 3.2 `brand_selling_points` 营销卖点库

用途：存储经过人工整理（或由 AI 辅助生成后确认）的营销卖点。

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| `id` | BIGINT UNSIGNED | 主键ID |
| `product_id` | BIGINT UNSIGNED | 所属产品ID，对应 `brand_products.id` |
| `title` | VARCHAR(255) | 卖点标题（如：全渠道一站式矩阵管理） |
| `description` | TEXT | 卖点详细描述 |
| `type` | VARCHAR(32) | 卖点类型：required (必打卖点), optional (可选卖点), forbidden (禁用表达) |
| `weight` | INT | 权重/评分 (0-10) |
| `source` | VARCHAR(32) | 来源：manual (手动新增), ai (AI提取), external (外部导入) |
| `status` | VARCHAR(32) | 状态：draft (草稿), confirmed (已确认), pending_confirm (待审) |
| `platforms` | JSON | 适用平台数组，如 ["douyin", "xiaohongshu"] |
| `applicable_scenarios` | JSON | 适用场景数组 |
| `is_deleted` | TINYINT(1) | 逻辑删除标记：0否，1是 |
| `created_at` | DATETIME | 创建时间 |
| `updated_at` | DATETIME | 更新时间 |

**索引建议：**
- `idx_product_type`：`product_id + type`
- `idx_status`：`status`

---

### 3.3 `brand_visual_assets` 视觉素材库

用途：存储相关的媒体文件，可直接用于内容分发。

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| `id` | BIGINT UNSIGNED | 主键ID |
| `product_id` | BIGINT UNSIGNED | 所属产品ID，对应 `brand_products.id` |
| `asset_type` | VARCHAR(32) | 素材类型：brand_logo, product_ui, promo_img, video_asset, etc. |
| `asset_url` | VARCHAR(512) | 素材资源 URL |
| `thumbnail_url` | VARCHAR(512) | 缩略图 URL |
| `tags` | JSON | 标签数组 |
| `platforms` | JSON | 适用平台数组 |
| `applicable_scenarios` | JSON | 适用场景数组 |
| `usable_for_cover` | TINYINT(1) | 是否可用作封面：0否，1是 |
| `usable_for_video` | TINYINT(1) | 是否可用作视频素材：0否，1是 |
| `extra_data` | JSON | 其他元数据（分辨率、时长、大小等） |
| `is_deleted` | TINYINT(1) | 逻辑删除标记：0否，1是 |
| `created_at` | DATETIME | 创建时间 |
| `updated_at` | DATETIME | 更新时间 |

**索引建议：**
- `idx_product_asset_type`：`product_id + asset_type`

## 4. 业务规则说明

1. **扁平化设计**：当前阶段不强制拆分品牌与产品表，一个条目即代表一个特定品牌下的特定产品线，方便用户快速配置。
2. **数据隔离**：所有数据按 `user_id` 进行逻辑隔离，确保用户的商业资产安全性。
3. **扩展性**：卖点和素材字段均预留 `JSON` 类型，支持未来针对特定平台的个性化参数扩展。
4. **状态机控制**：卖点状态由 `draft` -> `confirmed` 流转，仅 `confirmed` 状态的卖点会被推送到 AI 生成流程中。

## 5. SQL 建表语句 (DDL)

```sql
-- =========================================================
-- 品牌研究域 - 品牌产品档案表
-- =========================================================
CREATE TABLE `brand_products` (
    `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    `user_id` BIGINT UNSIGNED NOT NULL COMMENT '归属系统用户ID',
    `brand_name` VARCHAR(64) NOT NULL COMMENT '品牌名称',
    `product_name` VARCHAR(128) NOT NULL COMMENT '产品/生产线名称',
    `positioning` TEXT DEFAULT NULL COMMENT '产品定位',
    `target_audience` TEXT DEFAULT NULL COMMENT '目标人群',
    `scenarios` TEXT DEFAULT NULL COMMENT '适用场景',
    `tone_voice` VARCHAR(255) DEFAULT NULL COMMENT '整体调性',
    `forbidden_phrases` JSON DEFAULT NULL COMMENT '禁用表达/风险词',
    `cover_url` VARCHAR(512) DEFAULT NULL COMMENT '档案封面图片URL',
    `is_deleted` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '逻辑删除标记：0否，1是',
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`id`),
    KEY `idx_user_brand` (`user_id`, `brand_name`),
    KEY `idx_product_name` (`product_name`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci COMMENT='品牌研究域-品牌产品档案表';

-- =========================================================
-- 品牌研究域 - 营销卖点库
-- =========================================================
CREATE TABLE `brand_selling_points` (
    `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    `product_id` BIGINT UNSIGNED NOT NULL COMMENT '所属产品ID',
    `title` VARCHAR(255) NOT NULL COMMENT '卖点标题',
    `description` TEXT DEFAULT NULL COMMENT '卖点详细描述',
    `type` VARCHAR(32) NOT NULL DEFAULT 'optional' COMMENT '卖点类型：required/optional/forbidden',
    `weight` INT NOT NULL DEFAULT 5 COMMENT '权重/评分 (0-10)',
    `source` VARCHAR(32) NOT NULL DEFAULT 'manual' COMMENT '来源：manual/ai/external',
    `status` VARCHAR(32) NOT NULL DEFAULT 'confirmed' COMMENT '状态：draft/confirmed/pending_confirm',
    `platforms` JSON DEFAULT NULL COMMENT '适用平台数组',
    `applicable_scenarios` JSON DEFAULT NULL COMMENT '适用场景数组',
    `is_deleted` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '逻辑删除标记：0否，1是',
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`id`),
    KEY `idx_product_type` (`product_id`, `type`),
    KEY `idx_status` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci COMMENT='品牌研究域-营销卖点库';

-- =========================================================
-- 品牌研究域 - 视觉素材库
-- =========================================================
CREATE TABLE `brand_visual_assets` (
    `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    `product_id` BIGINT UNSIGNED NOT NULL COMMENT '所属产品ID',
    `asset_type` VARCHAR(32) NOT NULL COMMENT '素材类型：brand_logo/product_ui/promo_img/video_asset',
    `asset_url` VARCHAR(512) NOT NULL COMMENT '素材资源URL',
    `thumbnail_url` VARCHAR(512) DEFAULT NULL COMMENT '缩略图URL',
    `tags` JSON DEFAULT NULL COMMENT '标签数组',
    `platforms` JSON DEFAULT NULL COMMENT '适用平台数组',
    `applicable_scenarios` JSON DEFAULT NULL COMMENT '适用场景数组',
    `usable_for_cover` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否可用作封面',
    `usable_for_video` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否可用作视频素材',
    `extra_data` JSON DEFAULT NULL COMMENT '其他元数据',
    `is_deleted` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '逻辑删除标记：0否，1是',
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`id`),
    KEY `idx_product_asset_type` (`product_id`, `asset_type`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci COMMENT='品牌研究域-视觉素材库';
```
