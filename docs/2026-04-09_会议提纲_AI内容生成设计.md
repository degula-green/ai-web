# AI内容自动化项目 - 阶段性进展与下一步开发规划会议提纲

## 一、 已有工作基础回

目前项目已完成整体框架搭建，进入功能模块快速迭代阶段：

1.  **基础设施架构**：
    *   完成了整体前后端框架的搭建与联调。
    *   **登录注册模块**：支持用户认证、权限管理的基础功能。
2.  **数据采集功能（初版）**：
    *   **关键词爬取**：初步实现基于关键词的行业数据抓取。

3.  **品牌库与授权管理（初版）**：
    *   初步完成品牌管理功能，支持品牌资产（话术、卖点、视觉素材）的初步录入与管理。
    *   **平台授权功能**：初步实现了多平台（如抖音、小红书等）的账号授权机制，为后续自动化发布打下基础。

## 二、 关键技术调研与深度分析

### 1. 核心底座：AgentPod 运行时中间件
这是目前我们最核心的参考/集成项目。其设计理念“CWD 即边界，Runtime 即主权”为我们的内容自动化平台提供了坚实的底座。

*   **四大核心模块架构**：
    *   **AI 推理模块 (`/v1/query`)**：支持 SSE 流式输出，内置 **EventBuffer** 机制支持断线重连。通过 **ReAct (Reasoning and Acting)** 逻辑实现工具调用闭环。
    *   **隔离工作空间 (`/v1/cwd`)**：为每个用户/品牌分配物理隔离的文件夹，通过 `safe_resolve` 逻辑确保文件读写安全性。
    *   **管理与治理模块 (`/v1/admin`)**：具备完善的用户生命周期管理、用量统计及**资源配额监控**（如 CPU/内存水位报警）。
    *   **自动化调度 (`/v1/cron`)**：基于 `croniter` 实现内容的 24/7 自动抓取、生成与分发任务。
*   **关键技术细节**：
    *   **精准抓取**：内置 `web_fetch` 工具，通过正则清洗 HTML 仅保留有用文本，极大节省 Token 消耗。
    *   **成本熔断**：具备 Budget 系统，达到费用阈值自动触发熔断，防止 API 费用失控。
    *   **多模型兼容**：支持通过环境变量快速切换火山引擎、智谱等多种 Provider。

### 2. 视频多模态理解 
*   **核心能力**：
    *   **视频结构化**：不仅仅是转文字，而是基于字节跳动的 LVM 算子对视频的“分镜”、“场景动作”进行语义化解读。
    *   **关键点提取**：自动识别视频中的“导流钩子”、“核心卖点展示”等关键节点，为 AI 模仿提供蓝图。
*   **集成思路**：作为 AgentPod 的一个扩展 **Skill** 整合，通过 `v1/query` 中的多模态接口进行调用。

### 3. 素材抓取与解析
*   **功能定位**：内容生成的“原材料加工厂”。
*   **职责**：负责解析用户提供的 URL，获取无水印原片、背景音乐、封面及评论区热评，作为 AI 创作的原始素材。

## 三、 未来设计方向与技术实现思路 

### 1. AI 内容生成流程设计 
*   **输入态**：支持“链接输入”和“文本素材输入”。
*   **处理态**：
    1.  **解析**：调用下载 API 获取原始素材。
    2.  **解读**：调用 VLM 模型解析视频结构（分镜、脚本、卖点）。
    3.  **仿写**：利用最新的 **Imitation Skills**，基于解析出的结构及品牌库中的卖点，进行“素材 + 文本”的组合创作。
*   **输出态**：生成全新的视频拍摄脚本、AI 语音文案或分镜说明。

### 2. AI 模型管理策略
*   **争议点**：配置文件 vs. 数据库持久化。
*   **建议方案**：**混合模式**。
    *   **基础配置**：API Endpoint、版本等写死在配置文件（或环境变量），保证运行时的高性能与自愈能力。
    *   **动态管控**：Token 消耗记录、模型启用状态、用户权限绑定存入数据库（通过 AgentPod 的用户管理功能实现）。

### 3. “仿写”技能 (Skills) 的工程化实现
*   **实现路径**：基于上司提供的 Skill 框架，将其封装为 AgentPod 的标准 Skill。
*   **核心逻辑**：
    *   **语义对齐**：将品牌卖点与爆款文案的逻辑进行融合。
    *   **风格迁移**：通过 Prompt Engineering 模仿特定博主或特定品类的叙事风格。
